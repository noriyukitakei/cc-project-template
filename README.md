# cc-project-template

『ハーネス＆ループで自走するAI駆動開発』（技術評論社、2026年）のサンプルコードリポジトリです。
要件定義から設計・実装・コードレビュー・テストまでを一貫して進めるための、Claude Code 用プロジェクトテンプレートです（cc は Claude Code の略です）。

> 本リポジトリは書籍のサンプルであり、Anthropic の公式プロジェクトではありません。

## 前提条件

- Claude Code
- Docker と VS Code（Dev Containers 拡張機能）… `.devcontainer/` の隔離コンテナで動かす場合

## クイックスタート

```bash
git clone https://github.com/noriyukitakei/cc-project-template.git
cd cc-project-template
claude
```

Claude Code が起動したら、次のコマンドを実行します。

```text
/initial-project   … アイデア検討 → 要件定義 → 基本設計 → 詳細設計（最初に一度）
/feature           … 機能の追加（実装・コードレビュー・テストまで）
```

> 初回の起動時に、`.mcp.json` の Playwright MCP サーバーを使うか確認されるので、承認してください。

## 書籍との対応

| やりたいこと | 書籍の解説 |
|---|---|
| 全体像とディレクトリ構成をつかむ | 5-1 ディレクトリ構成と全体像 |
| まず一周試す | 5-2 まず使ってみる ― ToDo アプリで一周する |
| 設計書を作る（`/initial-project`） | 5-3 初期化のドキュメント作成 |
| 機能を追加する（`/feature`） | 5-4 実装とコードレビュー |
| テスト仕様書を作る | 5-5 テスト仕様書の作成 |
| テストコードを作って実行する | 5-6 テストコードの作成と実行 |
| 隔離コンテナ・権限設定・フック | 5-7 開発環境と強制の層 |

工程の順序や成果物の置き場所の正本は [`CLAUDE.md`](./CLAUDE.md) です。
